# Ticket Booking System

A backend ticket booking system built using Java and Spring Boot.

## Tech Stack

- Java
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Maven

## Features

- Movie management
- Theatre and screen management
- Show management
- Seat booking
- User accounts
- Booking management
- Payment handling

## Project Status

🚧 Currently under development.

## How to Run

1. Clone the repository.
2. Configure PostgreSQL.
3. Set the required database environment variables.
4. Run the Spring Boot application.

The application runs on:

`http://localhost:8083`
